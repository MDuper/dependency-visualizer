# Визуализатор зависимостей npm-пакетов

Консольное приложение на Python для анализа и визуализации графа зависимостей пакетов npm.

Вариант №8.

## Этап 1. Минимальный прототип с конфигурацией

На первом этапе реализовано CLI-приложение с настройкой через параметры командной строки.

Поддерживается:

- получение параметров командной строки с помощью `argparse`;
- вывод параметров в формате «ключ: значение»;
- установка значений по умолчанию для необязательных параметров;
- включение тестового режима;
- обработка ошибок при вводе некорректных параметров;
- автоматический вывод справки с помощью `--help`.

## Этап 2. Сбор данных

На втором этапе реализовано получение прямых зависимостей npm-пакетов из удалённого реестра.

Поддерживается:

- отправка HTTP-запросов с помощью `urllib.request`;
- получение информации о пакете в формате JSON;
- определение актуальной версии пакета по тегу `latest`;
- извлечение и вывод прямых зависимостей с ограничениями версий;
- обработка HTTP-ошибок и проблем с соединением;
- обработка некорректного JSON и отсутствующих ключей;
- вывод сообщения при отсутствии прямых зависимостей.

Для получения данных используется URL репозитория, переданный через параметр `--repo-url`. Менеджер пакетов npm не используется.

## Этап 3. Основные операции

На третьем этапе реализовано построение графа зависимостей с использованием алгоритма DFS без рекурсии.

Поддерживается:

- обход транзитивных зависимостей с помощью стека;
- ограничение глубины анализа параметром `--max-depth`;
- исключение пакетов по подстроке `--filter`;
- обработка циклических зависимостей;
- учёт минимальной глубины посещения пакетов;
- тестовый режим с загрузкой графа из текстового файла.

Для тестирования используется файл `tests/graph.txt`, в котором пакеты обозначены заглавными латинскими буквами.

Формат тестового репозитория:

```text
A: B C
B: D E
C: F
D:
E: C
F: A
```

Для запуска в тестовом режиме:

```bash
./run.sh --package A --repo-url tests/graph.txt --test-mode --max-depth 3
```

Для проверки фильтрации:

```bash
./run.sh --package A --repo-url tests/graph.txt --test-mode --filter C
```

Проверены различные значения максимальной глубины, исключение пакетов и наличие циклических зависимостей.

## Этап 4. Дополнительные операции

На четвёртом этапе реализовано определение порядка загрузки зависимостей с помощью DFS без рекурсии.

Поддерживается:

- формирование порядка, при котором зависимости обрабатываются раньше использующих их пакетов;
- исключение повторной обработки пакетов;
- защита от зацикливания при циклических зависимостях.

Проведено сравнение с менеджером пакетов npm на примерах `is-number` и `debug`. Состав зависимостей совпадает. При этом `npm ls --all` отображает дерево установленных пакетов, а разработанная программа — порядок их обработки.

Для циклических зависимостей строгий порядок загрузки невозможен.

## Параметры командной строки

Программа принимает следующие параметры:

- `--package` — название анализируемого npm-пакета (обязательный);
- `--repo-url` — URL репозитория или путь к тестовому файлу (обязательный);
- `--test-mode` — использование тестового репозитория;
- `--output` — имя выходного SVG-файла (по умолчанию `graph.svg`);
- `--ascii-tree` — включение вывода зависимостей в виде ASCII-дерева;
- `--max-depth` — максимальная глубина анализа (по умолчанию `3`);
- `--filter` — подстрока для исключения пакетов из анализа (по умолчанию пустая строка).

Параметры `--test-mode` и `--ascii-tree` являются флагами и не требуют указания значения.

## Обработка ошибок

Обрабатываются ошибки:

- отсутствие обязательных параметров;
- пустое название пакета;
- некорректный тип максимальной глубины;
- отрицательная глубина анализа;
- неправильное расширение выходного файла;
- некорректный формат URL репозитория;
- отсутствие указанного тестового файла;
- неизвестные аргументы командной строки.

При обнаружении ошибки программа выводит сообщение и завершает выполнение.

## Запуск

Запуск выполняется из корня проекта:

```bash
./run.sh --package express --repo-url https://registry.npmjs.org
```

Для первого запуска необходимо разрешить выполнение скрипта:

```bash
chmod +x run.sh
```

Для просмотра справки:

```bash
./run.sh --help
```

## Примеры использования

**Запуск с основными параметрами:**

```bash
./run.sh --package express --repo-url https://registry.npmjs.org
```

**Запуск с дополнительными параметрами:**

```bash
./run.sh --package express \
  --repo-url https://registry.npmjs.org \
  --max-depth 5 \
  --ascii-tree \
  --filter test \
  --output express.svg
```

**Запуск в тестовом режиме:**

```bash
./run.sh --package A --repo-url tests/graph.txt --test-mode
```

Для тестового режима необходимо предварительно создать файл `tests/graph.txt`.

На первом этапе программа только проверяет и выводит параметры. Получение зависимостей и построение графа будут реализованы на следующих этапах.
